# saSales Prediction Using Python

Project Overview

This project uses Python and Machine Learning to predict sales based on advertising expenditure across different platforms.

Objective

To understand how advertising on TV, Radio, and Newspaper influences sales and to predict sales using Linear Regression.

Dataset

The dataset contains advertising expenditure and sales information.

Features:

- TV
- Radio
- Newspaper

Target Variable:

- Sales

Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Project Workflow

1. Data loading and cleaning
2. Exploratory Data Analysis (EDA)
3. Data visualization
4. Feature selection
5. Training a Linear Regression model
6. Sales prediction

Expected Outcome

The project aims to identify which advertising platforms are associated with sales and use the trained model to estimate sales for a given advertising budget.

Conclusion

This project demonstrates how Python and Linear Regression can help analyze advertising data and support data-driven marketing decisions.
